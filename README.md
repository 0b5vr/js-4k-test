# js-4k-template

A simple TypeScript 4kb WebGL intro template?

## Prerequisites

- [Node.js](https://nodejs.org)
- [pnpm](https://pnpm.io)
- [Deno](https://deno.land)
- [Shader Minifier](https://github.com/laurentlb/shader-minifier)
- [Zopfli](https://github.com/google/zopfli)

## Build

```sh
pnpm install
pnpm build
```
